# Basic Weather App

## Description

The Basic Weather App is a Python application that allows users to check the weather of a city by entering its name. It fetches weather information from a weather API and displays the results.

## Features

* Search weather by city name.
* Fetch real-time weather information using an API.
* Display weather details such as temperature and weather conditions.
* Simple and easy-to-use interface.

## Technologies Used

* Python
* Requests library
* Weather API

## Requirements

* Python 3.x
* Requests library
* A valid API key from your chosen weather API provider, if required.

## Installation

Install the required library using:

```bash
pip install -r requirements.txt
```

## How to Run

1. Download or clone the repository.

2. Open the project folder in VS Code.

3. Open the terminal.

4. Run the application:

   ```bash
   python weather_app.py
   ```

5. Enter the city name when prompted.

6. View the weather information displayed by the application.
