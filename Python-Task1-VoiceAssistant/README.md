# Python Voice Assistant

## Project Description
A voice assistant developed using Python that accepts voice input and responds to the user.

## Features
- Speech recognition
- Voice responses using text-to-speech
- Voice-based interaction

## Technologies Used
- Python
- SpeechRecognition
- pyttsx3
- PyAudio

## Requirements
The project requires the libraries listed in Requirements.txt.

## How to Run
1. Install Python on your computer.
2. Install the required libraries:

   pip install -r Requirements.txt

3. Run the program:

   python voice_assistant.py
