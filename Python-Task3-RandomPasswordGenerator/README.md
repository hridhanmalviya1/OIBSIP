# Random Password Generator

## Description

A simple Python project that generates random passwords based on the length specified by the user. It uses letters, numbers, and special characters to create passwords.

## Features

* Generate random passwords.
* Customize password length.
* Include uppercase and lowercase letters.
* Include numbers and special characters.
* Simple and user-friendly interface.

## Technologies Used

* Python
* `random` module
* `string` module

## Requirements

* Python 3.x
* No external libraries required.

## How to Run

1. Download or clone this repository.

2. Open the project folder in VS Code.

3. Open the terminal.

4. Run the following command:

   ```bash
   python password_generator.py
   ```

5. Enter the desired password length when prompted.

6. View your generated password.
