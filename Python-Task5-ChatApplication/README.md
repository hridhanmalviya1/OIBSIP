# Real-Time Chat Application in Python

## Description

The Real-Time Chat Application is a Python-based project that allows multiple clients to communicate with each other through a central server using socket programming and multithreading.

## Features

* Real-time message exchange between clients.
* Multiple client connections.
* Server-based message broadcasting.
* TCP socket communication.
* Multithreading for handling multiple clients simultaneously.
* Simple command-line interface.

## Technologies Used

* Python 3
* Socket Programming
* TCP/IP Networking
* Multithreading

## Requirements

* Python 3.x
* No external libraries required.

## Python Modules Used

* `socket` – Establishes network communication.
* `threading` – Handles multiple clients simultaneously.
* `sys` – Provides access to system-specific functionality.

## Project Structure

```text
Chat-Application/
├── server.py

```

## How to Run

### Step 1: Open the Project

Open the project folder in VS Code.

### Step 2: Start the Server

Open a terminal and run:

```bash
python server.py
```

### Step 3: Start the Client

Open another terminal and run:

```bash
python client.py
```

### Step 4: Connect Multiple Clients

Run the client program in additional terminals to connect multiple users and exchange messages.
